ABOUT THE PROJECT
-----------------
This is my personal portfolio website. It shows who I am, my skills,
my projects, my education and certificates, and how to contact me.
It was made for the "Personal Portfolio Website Design and Development"
assignment.

The design has a dark robot and circuit-board theme, with a robot face in
the background whose eyes follow the mouse.


SECTIONS
--------
1. Home       - name, profile photo, headline and short introduction
2. About Me   - who I am, interests, education and career goal
3. Skills     - technical skills (beginner level) and other skills
4. Projects   - events_hub, API and student_portfolio, with links
5. Education  - diploma, school, and three Coursera certificates
6. Contact    - email, phone, location, GitHub and a contact form


FEATURES
--------
- Responsive layout for desktop, tablet and mobile
- Welcome screen with "Enter with music" and "Enter silent" buttons
- Background music (made live in the browser with the Web Audio API,
  no audio file needed) with an on/off button
- Dark and light theme toggle (the choice is remembered)
- Mobile hamburger menu and highlighted menu link for the current section
- Typing animation and a greeting that changes between Kuzuzangpo la,
  Namaste and Hello
- Moving particle background that reacts to the mouse
- Robot face with eyes that follow the mouse
- Animated skill bars and a scrolling skills strip
- Project filter buttons (All, Web, JavaScript, API)
- 3D tilt effect on project and certificate cards
- Contact form with validation (it opens the email app to send the message)
- Scroll progress bar and back-to-top button
- Respects the "reduce motion" setting for accessibility


TECHNOLOGIES USED
-----------------
- HTML5
- CSS3 (Flexbox, Grid, CSS variables, animations)
- JavaScript (no frameworks or libraries)
- Google Fonts: Chakra Petch and JetBrains Mono (needs internet)

HOW TO RUN ON YOUR COMPUTER
---------------------------
1. Download or clone the repository.
2. Keep all files in the same folder.
3. Double-click index.html to open it in a browser.
   (Optional: use the VS Code "Live Server" extension.)


HOW TO DEPLOY WITH GITHUB PAGES
-------------------------------
1. Upload all files to the main folder of the public repository
   "student_portfolio".
2. Go to Settings > Pages.
3. Under "Build and deployment", choose Deploy from a branch,
   select branch "main" and folder "/ (root)", then click Save.
4. Wait about one minute. The site will be live at:
   https://05240163jnec-pixel.github.io/student_portfolio/
